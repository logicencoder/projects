# Additional operator tools

[Back to the project catalogue](../README.md)

Focused operator and development tools maintained alongside the larger applications. These summaries describe purpose, not access instructions or private deployment details.

## DNX Bridge

Prepare and inspect bridge claims, review available capacity and control supported automatic claiming.

## Dynex MEXC Balance Monitor

Inspect published Dynex exchange in/out activity, balances and related analytics.

## DNX Chain Checker

Follow DNX-related swaps, transfers and monitored-wallet activity in a terminal workspace.

## Basic CEX/DEX Comparator

Compare DNX exchange trades with decentralized quotes at different trade sizes, with gas-cost context.

## Chain Watchers

A toolkit for monitoring Ethereum swap activity.

## Proxy Pool Monitor

Review the availability and health of a shared fallback proxy pool.

## MT5 Fleet Tools

Operate and maintain MetaTrader 5 strategy-testing worker environments.

## Tokyo VPN

Control a WireGuard client through a desktop window and tray interface.

## Red-Team Lite

Run authorized web-application security checks and retain browser evidence and reports.
